マイタスク 操作マニュアル

LINEで送る言葉と、自動で届くものの一覧です。迷ったらこのページを見てください。

1. 1日の流れ

基本は「朝に確認 → 夜に答え合わせ → 明日を決める」の繰り返しです。何もしなくてもLINEから声がかかります。

  • 6:00期限が近いタスクのリマインド（番号つき）。時間が未設定のものは別メッセージで時間を聞かれます。
  • 8:00今日やることを決める最終期限。決まっていなければ催促が来ます。
  • 20:00AIコーチの進捗チェックイン ＋ 日報。期限未設定のタスクもここでまとめて聞かれます。
  • 22:30今日決めた予定の答え合わせ。できていないものはそのままリマインドされます。
  • 23:30明日やることの洗い出し。番号を返すだけで確定します。
  • 24:00今日の振り返りを一言。1時間返信がなければもう一度だけ催促します。
  • 日曜21:00週報（完了数・ペース・前週比・積み残し）。

このほか、時刻を設定したタスクは開始10分前に、定期タスクは設定時刻にリマインドが届きます。

3. タスクを追加する

やることをそのまま送るだけで追加されます。

送り方の例

  • 牛乳を買う … 期限なしで追加（このあと期限を聞かれます）
  • 牛乳を買う 6/25 … 末尾に日付で期限つき
  • 会議の準備 6/25 15:00 … 日付＋時刻
  • 今日17時に小室くんにチラシの件伝える … 文の途中の日付・時刻も読み取ります

今日／明日／明後日、6/25、15時／15時30分／15:00 に対応しています。

  • 期限を書かずに送ると、その場で「期限はいつ？」と聞かれます（不要なら なし）。
  • 期限が今日・明日・明後日なら、続けて時刻も聞かれます（不要なら なし）。
  • 長い文章や箇条書きを送ると、AIが要点だけのタスク名に整理して追加します。

4. 番号で操作する（いちばん速い）

「一覧」「通知」「日報」「週報」など番号つきのメッセージが届いたら、その番号だけで操作できます。タスク名を打ち直す必要はありません。番号は表示から12時間有効です。

送る言葉結果
1完了1番を完了にする
1削除1番を削除する
5ペンディング5番をペンディングにする
2着手中 / 4対応待ち状態を変える
1削除 5ペンディングまとめて指定
1明日 / 2を7/30期限だけ変える（リスケ）
1 15時 / 2は10時30分時間を設定する
3 明日10時期限と時間をまとめて設定
3番のタイトルを〜に書き換えて細かい指示は「3番の〜」と続ける

番号が分からなくなったら 一覧 と送れば振り直されます。

5. 今日やることを決める

毎晩23:30に、翌日の候補が番号つきで届きます。

やりとりの例

ボット：🌙 明日（7/29）やることを決めましょう
　1. ctrip問い合わせ（6/24）
　2. 仕入れ先に連絡（7/29）
　3. WIFIルーターを探す（期限なし）

あなた：1,2

→ 翌日22:30に「できたか」の答え合わせが届きます。できていないものは番号つきで出るので、1完了 や 1明日 でその場で処理できます。

  • 自分から決めたいときは 予定を決める（20時より前ならその日ぶん、20時以降なら翌日ぶん）。
  • 候補を全部やるなら 全部、決めないなら なし。
  • 決まっていないと 0:30 / 6:30 / 8:00 に催促が来ます（朝8時が最終期限）。
  • 今の進み具合を見るには 今日の予定。

6. 定期タスク（繰り返し）

毎日・毎週・毎月くり返す予定は「定期タスク」として登録します。ボードには自動で増えません。指定した時刻にLINEでリマインドが届くだけの仕組みです。

登録のしかた（周期を文に入れて送る）

  • 毎週月曜19時に週報を出す を定期タスクにして
  • 毎月末日に家賃を振り込む を定期タスクとして登録して
  • 毎日8時に売上を確認する を定期タスクに

時刻を書かなければ、毎朝6:00の通知と同じタイミングでお知らせします。

  • 登録済みを見るには 定期タスク。
  • リマインドは通常の一覧とは別メッセージで届きます。

変更・削除もLINEでできます

  • 週報を出すのリマインド時間を20時にして … 時刻だけ変更
  • 家賃振込を毎月25日に変更して … 周期・曜日・日にちを変更
  • 家賃振込を削除して … 定期タスクを削除

7. Googleカレンダー連携

自分のカレンダーを共有しておくと、空き時間を踏まえた提案が受けられます（未設定の場合はこの章は関係ありません）。

  • カレンダー … 今日・明日の予定と空き時間を表示

予定の追加・変更・削除

  • 明日14時から16時 仕込み をカレンダーに入れて
  • 毎週月曜10時に定例MTG をカレンダーに入れて … 繰り返しの予定
  • 明日のバイトを17時からに変更して
  • 〇〇の通知を15分前にして
  • 31日の神田をキャンセルして

追加・変更・削除は、実行前に必ず「はい」の確認が入ります（5分以内）。繰り返しの予定への変更・削除は、指定した1回分だけに適用されます。

連携していると、毎朝の通知・予定を決めるとき・時刻の設定・AIコーチの助言に、その日の空き時間が自動で反映されます。

8. AIコーチに頼めること

タスク名を全部書かなくても、キーワードだけで候補が1つに絞れればAIが判断します。

  • 会議資料の準備を分解して … サブタスク案 →「はい」で追加
  • 牛乳を買うを完了にして / 〜を削除して
  • 〇〇の期限を7/1にして / 〇〇の優先度を上げて
  • 〇〇を△△に書き換えて … タスク名の修正
  • 優先順位を整理して … 並べ替え案 →「はい」で適用
  • 相談 / このタスクやる意味ある？ … 率直な意見が返ります
  • 要約して / まとめて … 今の状況を簡潔に

9. 資料と振り返り

資料

  • YouTubeのURLを送る、または 資料：本文 の形式で送ると、AIが要点を要約して覚えます。
  • 以降の相談で参考にします。確認は 資料。
  • 理解がズレていたら 〇〇の資料を△△に直して で書き直せます。

振り返り

  • 毎晩24時に催促が来るので、そのまま普通の文章で返せば記録されます。
  • 自分から書くときは 振り返り と送ってから本文、または 振り返り：今日は仕込みが早く終わった。
  • 週報やAIコーチの相談で参考にされます。

10. レポート

  • 日報 … 今日の完了件数、今日が期限のものの達成率、期限切れ、未完了数、直近7日のペース
  • 週報 … 直近1週間の完了数とペース、前週比、積み残し、振り返りログ

どちらも番号つきなので、その場で「1完了」「1明日」と返せます。日曜21:00には週報が自動で届きます。

11. 困ったとき

  • タスクじゃないのに追加されてしまう … その場で 1削除（直前の番号）で消せます。
  • 番号が効かない … 12時間経つと無効になります。一覧 で振り直してください。
  • メニューが古いまま … トーク画面を閉じて開き直す、それでもだめならLINEアプリを再起動。
  • 反応がない … 少し待ってもう一度送ってください。それでもだめなら開発担当（Claude）に連絡を。
