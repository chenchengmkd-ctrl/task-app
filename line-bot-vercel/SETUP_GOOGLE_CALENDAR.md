# Googleカレンダー連携の設定（1回だけ・無料）

自分のカレンダーの予定を読んで、「その日の空き時間」を踏まえた提案ができるようにします。
**カードの登録は不要です。**Googleカレンダーの読み取りは無料の範囲だけを使います。

やることは大きく3つです。

1. Google側で「読み取り専用のロボット用アカウント（サービスアカウント）」を作る
2. 自分のカレンダーを、そのロボットに「見るだけ」で共有する
3. カギ（JSONファイル）の中身をVercelに登録する

所要 15〜20分ほど。途中で分からなくなったら、その画面のスクリーンショットを送ってください。

---

## STEP 1：Googleのプロジェクトを作る

1. `https://console.cloud.google.com/` を開く（Googleアカウントでログイン）
2. 初回は国と利用規約の同意画面が出るので、国＝日本、規約にチェック →「同意して続行」
3. 画面上部の左寄りにある **プロジェクト選択（「プロジェクトの選択」または既存の名前）** をクリック
4. 右上の **「新しいプロジェクト」** をクリック
5. プロジェクト名に `mytask-calendar` と入力 →「作成」
6. 作成が終わったら、もう一度上部のプロジェクト選択から **`mytask-calendar` を選ぶ**

> 💡 ここで「お支払い情報の登録」を求められることはありません。求められた場合は先に進まず教えてください。

## STEP 2：カレンダーAPIを使えるようにする

1. 上部の検索窓に **`Google Calendar API`** と入力して、出てきた項目をクリック
2. **「有効にする」** ボタンをクリック（数十秒かかります）

## STEP 3：ロボット用アカウント（サービスアカウント）を作る

1. 左上の **≡（三本線）** →「APIとサービス」→ **「認証情報」**
2. 上部の **「＋ 認証情報を作成」** → **「サービス アカウント」**
3. サービスアカウント名に `mytask-bot` と入力 →「作成して続行」
4. 「ロールを選択」は **何も選ばずに「続行」**（カレンダー側で権限を渡すので不要）
5. 最後の画面も何も入れずに **「完了」**

## STEP 4：カギ（JSONファイル）をダウンロードする

1. 「認証情報」の画面に、いま作った **`mytask-bot@…iam.gserviceaccount.com`** が出ています
2. そのメールアドレスをクリック → 上部タブの **「キー」**
3. **「鍵を追加」→「新しい鍵を作成」** → 形式は **JSON** のまま **「作成」**
4. `mytask-calendar-xxxxx.json` のようなファイルがダウンロードされます（これがカギです）

> ⚠️ このファイルはパスワードと同じ扱いです。人に送らないでください。

5. **`mytask-bot@…iam.gserviceaccount.com` というメールアドレスをコピーしておいてください**（次で使います）

## STEP 5：自分のカレンダーをロボットに共有する

1. `https://calendar.google.com/` を開く
2. 左側「マイカレンダー」の中の、**自分の名前のカレンダー**にマウスを乗せる → **⋮** → **「設定と共有」**
3. 下にスクロールして **「特定のユーザーまたはグループと共有する」** → **「ユーザーやグループを追加」**
4. STEP 4でコピーした **`mytask-bot@…iam.gserviceaccount.com`** を貼り付け
5. 権限は **「すべての予定の詳細を表示」** を選ぶ（変更権限は渡さないでください）
6. **「送信」**

7. 同じ設定画面の下の方にある **「カレンダーの統合」** の中の **カレンダーID**（ふつうは自分のGmailアドレス）をコピーしておく

## STEP 6：Vercelに登録する

1. `https://vercel.com/` を開いて、`task-app` のプロジェクトを選ぶ
2. 上部の **Settings** → 左メニューの **Environment Variables**
3. 次の2つを追加します（1つずつ「Add another」で追加 → 最後に Save）

| Key | Value |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | STEP 4のJSONファイルを**メモ帳で開いて、中身を全部コピペ**（`{` から `}` まで丸ごと） |
| `GOOGLE_CALENDAR_ID` | STEP 5でコピーしたカレンダーID（ふつうは自分のGmailアドレス） |

4. 保存したら、上部 **Deployments** → 一番上の行の右端 **⋯** → **Redeploy** →「Redeploy」

## STEP 7：確認

LINEで **「カレンダー」** と送ってください。今日と明日の予定、空き時間が返ってくれば成功です。

うまくいかないときは、ブラウザで次を開いて `calendar_check` の部分を送ってください。

```
https://task-app-nine-liard.vercel.app/api/health
```

- `"enabled": false` … Vercelの環境変数が入っていない（STEP 6をもう一度）
- `"today_events": 0` が続く … 共有先のメールアドレス、またはカレンダーIDが違う可能性（STEP 5）

## 連携すると何が変わるか

| 場面 | 動き |
|---|---|
| 毎朝6:00 | 期限リマインドの後に、その日の予定と空き時間が届く |
| 予定を決めるとき（23:30） | 「🗓 空き時間：14:00-17:00（合計3時間）→ 1件1時間で見ると、およそ3件ぶん」と先に表示 |
| 番号で時刻を設定するとき | 予定と重なっていたら警告し、空いている時刻を提案 |
| 時間未設定タスクの確認 | 今から後の空き時間を添えて表示 |
| 定期タスクのリマインド | 予定と重なる時間帯なら、空く時間まで自動でずらす |
| AIコーチの相談・チェックイン | 予定と空き時間を前提にしたアドバイスになる |

設定しなくても、これまでどおり全機能そのまま使えます（カレンダー関連の表示が出ないだけです）。
