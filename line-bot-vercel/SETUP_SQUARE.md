# Square（レジ）連携の設定

Squareで打った売上を、財務アプリの「売上」に自動で取り込むための設定です。
コード側はすでに入っているので、**アクセストークンを1つ発行してVercelに登録するだけ**です。

⚠️ **アクセストークンは、Squareのお金に関わる情報を読める鍵です。**
チャットやメールに貼らず、Vercelの管理画面に直接入力してください。

---

## STEP 1. Squareでアクセストークンを発行する

1. https://developer.squareup.com/apps を開く
2. いつもレジで使っているSquareアカウントでログイン
3. 「＋」または「Create your first application」でアプリを作る
   - 名前は何でもよい（例：`oneburg-finance`）
4. 作ったアプリを開く
5. 画面上部（または左上）の環境切り替えを **Sandbox → Production** に変える
   - ここが Sandbox のままだと、テスト用の架空データしか取れません
6. 「Credentials」の中の **Production Access Token** の「Show」を押してコピー
   - `EAAA...` で始まる長い文字列です

### 権限について
自分のアカウント用のトークンなので、追加の権限設定は基本的に不要です。
もし権限を選ぶ画面が出たら、次の2つにチェックが入っていればOKです。

| 権限 | 用途 |
|---|---|
| `PAYMENTS_READ` | 売上（決済）の読み取り |
| `MERCHANT_PROFILE_READ` | 店舗（Location）の取得 |

**書き込み権限は一切不要です。** このコードはSquareから読むだけで、書き込みは行いません。

---

## STEP 2. Vercelに登録する

1. https://vercel.com/ を開いてログイン
2. `task-app`（line-bot）のプロジェクトを開く
3. **Settings → Environment Variables**
4. 次を追加：

| Name | Value |
|---|---|
| `SQUARE_ACCESS_TOKEN` | STEP 1でコピーしたトークン |

5. 「Save」
6. **Deployments** タブ → 最新のデプロイの「…」→ **Redeploy**
   - 環境変数は再デプロイしないと反映されません

### 店舗が複数ある場合だけ
店舗が1つなら不要です（自動で選びます）。複数ある場合は、下の確認URLに出る
`locations` から使いたい店舗の `id` を選び、`SQUARE_LOCATION_ID` として同じ手順で追加してください。

---

## STEP 3. 動作確認

ブラウザで開く：

```
https://task-app-nine-liard.vercel.app/api/health
```

`square_check` が次のようになっていれば成功です。

```json
"square_check": {
  "enabled": true,
  "ok": true,
  "locations": [{ "id": "L...", "name": "屋台うなぎ", "currency": "JPY" }],
  "today": { "total": 41200, "count": 23, "by_source": { "CASH": 28000, "CARD": 13200 } }
}
```

うまくいかないとき：

| 表示 | 原因 |
|---|---|
| `"enabled": false` | トークンが未設定、または再デプロイしていない |
| `"ok": false` | トークンが違う／Sandbox用のトークンを入れている |
| `today.total` が0 | その日の売上がまだ無いだけ（夜に確認すれば入ります） |

## 使い方

### LINEから

| 送る言葉 | 動き |
|---|---|
| `スクエア` | その日のSquare売上を確認（**書き込まない**） |
| `スクエア取込` | アプリの売上に反映する |
| `スクエア 8/5` | 日付を指定して確認 |
| `スクエア取込 8/5` | 日付を指定して反映 |
| `取り消し` | 直前の取り込みを戻す |

### 自動取り込み

**毎晩23:30に自動で取り込みます。**

- その日の売上がまだ入っていなければ、Squareの金額を入れてLINEで知らせます
- すでに手で入れてある場合は**上書きしません**。金額が違うときだけ「Square ◯円 ／ アプリ ◯円」と知らせるので、
  必要なら「スクエア取込」で合わせてください

---

## 取り込まれる金額について

- **現金もカードも両方含みます。** Squareで打った決済すべてが対象です。
  LINEの確認メッセージに現金・カードの内訳が出るので、そこで確かめられます
- **返金は差し引いて**計算します
- **未確定の決済（与信のみ）は含みません**（`COMPLETED` のみ集計）
- 金額は**税込**です。アプリ側の売上欄も税込なのでそのまま入ります
  （税抜は日次入力画面の税率設定にもとづいて自動計算されます）

### 注意
Squareを通さない売上（レジを使わずに受け取った現金など）は当然入りません。
その分は日次入力画面で足してください。
